# MoveBit 使用指南

中文 · [English](USER-GUIDE.md)

喝水、起身、护眼三类健康提醒，由小家伙沐比（Mubi）交付——每次休息它都走到屏幕中央，置顶等你回应；没有提醒时它在旁边自己玩耍。它从不抢键盘焦点、从不遮挡工作，除沐比本体外的屏幕全部鼠标穿透。

## 可用性

当前公开预览版：源码采用 MIT 许可，尚未启用付费激活或订阅。实际可下载版本以 Releases 为准；本手册不将历史基线 v0.0.1 当作最新版本。

## 平台与安装

正式发布覆盖 Windows x64、macOS（Apple silicon 与 Intel）和 Linux x64/arm64。每个平台都有便携压缩包；Windows 另有 MSI，macOS 有 DMG，Linux 有 deb、rpm 与 AppImage。请使用[官方 Releases](https://github.com/turlamai/movebit/releases)，选择明确列出的系统/架构资产并核对发布页的 `SHA256SUMS` 校验文件。预览资产可能缺少签名或公证；不要为安装关闭系统级安全保护。

平台说明：空闲检测使用系统原生 API（GetLastInputInfo / CoreGraphics / XScreenSaver）。Linux 上沐比角色卡在 X11 会话停靠；Wayland 合成器不允许应用自行放置穿透卡片，提醒改为应用内提醒卡投递（提醒、历史与更新照常工作）。

## 你的第一次使用

1. 安装并启动。单页欢迎界面展示沐比、一句话说明和一个 **开始** 按钮，不再追问节奏；出厂节奏为「均衡」且默认静音，随时可在设置中调整。
2. 认识沐比。周期到点，角色走到工作区中央——在所有窗口之上——带着明确的健康建议**等你回应**。没有计时器会把它撤走，点击别处也没有任何反应。
3. 按你的方式回应：**摸摸沐比**（点一下角色本体——自我报告，不是实测）、气泡上的**稍后**标签（按 10 个活跃分钟延后），或托盘里的做到了 / 稍后 / 隐藏。除沐比本体外的屏幕保持鼠标穿透；托盘菜单随时可达全部动作。
4. 需要后台提醒再开「开机自启」。历史图表是使用估计，不是健康测量。

## 沐比、专注与诚实

- 三种手势对应三类提醒：久坐→起身拉伸、喝水→举小蓝杯、护眼→闭眼远眺。多个提醒同时到期会合并成一条，含义全部保留。
- **专注模式**（Windows / macOS 用托盘开关，Linux 用主窗口头栏按钮）在演示、会议时静默排队提醒，结束后只送回一条有界汇总——绝不堆积。开专注前已经显示的提醒不会被重发。
- 无人回应的邀请会一直留在屏幕上——沉默不会被记成完成，也不会丢失任何提醒。新一轮提醒触发时会合并进未回应的那条：屏幕上永远只有一只沐比，每种含义都保留。
- 没有提醒时，沐比会在自己的角落自己玩耍——翻滚、歪头、眨眼、小跳，像宠物在旁边耐心等主人。系统「减弱动态」会让一切保持静态。
- v0.0.1 里没有任何全屏强制休息，也没有开关能把它找回来——这是有意删除的契约。

## 节奏、免打扰与诚实

只有一条均衡节奏，它就是产品默认值，不可配置：起身每 50 活跃分钟、喝水每 60 分钟、护眼每 20 分钟（看远 20 秒）。「现在不想被打扰」在托盘里，不在设置里——**专注**整体延后、**暂停**静默一小时、**稍后**延后单条提醒。

- 计时基于**活跃时间**而非墙钟：离开电脑超过「离开判定」（5 分钟）就算一次真实休息，循环会重置。
- 设置窗口只保留四项：提示音（每次提醒一声轻响）、免打扰时段、自动检查更新、语言。
- **免打扰时段**会在本地时间窗口内（例如 22:00 到次日 07:00，可跨午夜）暂停全部提醒，结束后恢复；起止时间相同表示关闭。**专注**仍是会议/演示时的即时静音动作。
- 主界面会显示最近的下一条提醒，并按类别分别列出**实际展示**过的邀请数和你标记的**完成**数。「完成」只是你的自述，不代表真的喝了水、起了身或休息了眼睛。

## 工作历史

今日活跃分钟、提醒次数与 7/30 天图表都在主窗口；历史保留 370 天。活跃时间只统计真实的键鼠存在——超过离席阈值（默认 5 分钟）的空闲视为一次真正的休息并重置各周期。

## 数据、备份与恢复

退出 MoveBit 后备份 `config.json` 与 `history/` 文件夹：macOS `~/Library/Application Support/movebit`，Linux `~/.config/movebit`，Windows `%APPDATA%\movebit`。v1 配置文件带 `SchemaVersion` 标记；没有标记的外来文件会回落为默认值，而不是被半吊子迁移。恢复前先在副本上验证。

## 网络、密钥与隐私

提醒与统计全部本地完成。更新检查与下载只访问 GitHub Releases。没有账户、没有遥测、不记录按键——空闲检测只向操作系统询问「距离上次输入过去了多久」，仅此而已。沐比的面板不读取任何输入。

## 更新与卸载

应用内「检查更新」读取 Ed25519 签名的 `update-manifest.json`，下载后校验大小与 SHA-256，只通过「更新并重启」换新。任何校验失败都会中止，当前安装原封不动。卸载程序不会删除独立的数据目录；删除个人数据前先确认备份。

Windows 便携 ZIP 更新中，复制失败或 Windows 无法启动新程序时，会恢复旧安装并尝试重新启动它；失败原因写入应用数据目录下的 `updates/update-failed.txt`。Windows 接受启动请求不等于应用健康检查通过：后续崩溃、完整界面重启及真实版本回滚仍是独立验收门禁。MSI 更新交给 Windows Installer，不采用便携版目录替换流程。

替换 Windows 便携版安装前，辅助程序最多等待两分钟让旧进程退出。如果无法确认退出，会保持安装不变并记录「更新未应用」，不会强制结束应用。请正常关闭原应用后再重试更新。
