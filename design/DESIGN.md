# MoveBit — 桌面产品设计与交互契约

更新：2026-11-15。本契约对应当前可编辑桌面交互原型。桌面宠物是日常产品主体；统计与设置是按需打开的辅助窗口。原型不是 Web 产品的信息架构，也不等同于原生宿主已经实现。

## 产品目标与范围

为长时间使用电脑的人提供喝水、起身、护眼提醒。产品应有趣、简单、完整；不增加养成任务、积分、换装、强制全屏或配置迷宫。

保留全部已有能力：合并邀请、完成/部分完成/稍后/隐藏、暂停一小时、专注、免打扰时段、手动护眼和拉伸、今日记录、7/30 天历史、洞察、提示音、开机自启、语言、更新、数据位置、官网、反馈、角色复位与退出。

## 入口与页面

- `index.html` 与 `prototype/desktop.html`：直接进入桌面场景，沐比与到点邀请是主体，无网页导航、宣传标题、评审说明、页脚或展示型仪表盘。
- `prototype/main.html`：桌面中的辅助窗口，包含今日、历史、设置、关于四个窗口内分段。关闭后返回同一桌面，沐比继续存在。
- `prototype/empty.html`：使用独立零数据打开辅助窗口。无历史时诚实显示暂无记录。
- `prototype/tray.html`：桌面中的紧凑应用菜单，包含所有低频操作。菜单关闭后回到同一桌面。
- `prototype/micro.html`：紧凑休息窗口，有邀请、计时、结束三个实际状态。
- `prototype/onboarding.html`：一屏欢迎窗口，一个开始。开始后进入桌面。
- `prototype/shared.js` 与 `prototype/shared.css`：共用状态、角色、美术与窗口规则，无外部依赖。

六个独立文件仍可直接打开；它们表达同一产品的状态，而不是六个网站页面。普通操作在当前文档中切换窗口状态，不重新加载网页或跳转到页面。

## 桌面日常体验

平时只需一个沐比与小型菜单入口。原型用中性的桌面底色表达宿主外的工作区，不伪造某一平台的菜单栏、任务栏、窗口交通灯或桌面壁纸资产。

到点时，一条小邀请贴着沐比出现，多种提醒合并。提醒之外不弹出大窗口，不遮盖整屏，不抢用户任务的主角位置。

沐比旁的菜单按钮始终可用，不要求用户发现右键。场景边缘另有 MoveBit 系统入口示意，代表原生菜单栏/托盘集成点，并非浏览器已获得系统托盘能力。

辅助窗口打开时，宠物仍保留在工作区边缘。窗口关闭不等于退出应用，提醒不会被清空。退出必须通过明确菜单并确认。

## 沐比与趣味性

保留暖象牙身体、双叶鳍、豆眼和既有轮廓，用表情、小手与健康语义道具表达性格。

| 状态 | 表现 | 行为 |
|---|---|---|
| 日常等待 | 睁眼、微笑 | 安静，不无限循环蹦跳 |
| 初次见面 | 笑眼、举手 | 欢迎用户 |
| 喝水 | 捧小水杯 | 提醒喝水，未检测喝水行为 |
| 起身 | 小手展开 | 邀请站起来 |
| 护眼 | 闭眼、叶片提示 | 引导把目光移出屏幕 |
| 完成 | 笑眼、单次轻跃、小光点 | 明确完成后出现 |
| 稍后 | 闭眼、点头一次 | 不记完成，稍后再见 |
| 专注 | 戴耳机、闭眼 | 保持静止和静默 |
| 暂停/免打扰 | 闭眼休息 | 暂时收起邀请 |
| 被拎起 | 圆眼、小手张开、随方向轻倾 | 只移动位置 |
| 放下 | 单次轻压回弹 | 落稳后恢复原本状态 |
| 摸摸 | 开心、眨眼、探头依次回应 | 纯陪伴，不记录完成 |

合并邀请只呈现一个角色与一个主姿态。健康事项通过文字完整列出，不通过叠加多种道具表达。

角色动效为 360ms 单次反馈，控件反馈 200ms。短句只在最近互动后的约 2.2 秒出现，之后恢复安静。持续等待、稍后、专注不持续显示情绪气泡。提醒本身保持可见，直至用户回应。

减少动态效果时保留静态表情、道具与文案，不依赖跳跃或倾斜表达完成。

## 直接操作与防误触

**所有场景中的摸摸都只是摸摸，不再以点击宠物代表完成。**这一规则替代之前版本中“桌面点击等于全部完成”的设计。

- 鼠标或触控板主点击宠物：切换短暂表情，计数不变。
- 按住宠物本体并移动超过二维 8px：进入拖动；使用指针捕获，松开落位，取消也不提交健康回应。
- 拖动整个宠物及其邀请，不将宠物与提示拆散；位置限制在当前工作区范围内。
- 辅助窗口打开时将宠物放回边缘，避免挡住窗口。窗口尺寸变化时复位到安全位置。
- Tab 可聚焦宠物，Enter/空格等于摸摸，方向键移动宠物；不需要专有修饰键。
- 菜单按钮是主入口之一。右键宠物只是额外快捷入口，不是使用前提。
- 菜单支持上下键、Home/End 与 Esc。关闭辅助窗口或按 Esc 回到桌面，焦点有明确落点。
- 拖动姿态不会误记完成；完成只由邀请中的按钮、逐项确认、托盘完成项或休息窗口中的「做好了」提交。

原型只实现浏览器工作区内的直接操纵，不把 CSS 位移当作原生跨屏移动实现。

## 提醒与应答

- 一个沐比、一条邀请，到点类型取并集；每类至多一个待回应项。
- 「做到了」确认当前全部事项；「只做了一部分」展开逐项勾选，只记录所选，其余继续等待。零选择不提交。
- 起身完成会重置本轮连续活跃；喝水与护眼不会。
- 「稍后」表示 10 活跃分钟后再次提醒，不记完成。已有事项合并，不堆叠。
- 邀请右上关闭按钮表示「隐藏这次」，不记完成。菜单仍保留回应路径。
- 点击桌面空白不把提醒算完成，也不自动消灭持久邀请。
- 「暂停 1 小时」收起邀请，到期自动恢复，也可立即恢复。
- 「专注」收起邀请并静默，结束后只保留一次合并提醒，不补发队列。
- 免打扰支持跨夜；相同起止时间视为全天。时段内不弹出、不发声，结束后合并提醒。
- 邀请内容用日常短句，例如「起来走走，喝口水？」；不显示技术说明或要求用户学习状态机。

## 微休息

- 20 秒护眼与 2 分钟拉伸由用户主动开始；倒计时按截止时间计算。
- 进行中可停止或显式完成；停止、关闭窗口、Esc 与先收起来均不记完成。
- 结束后保留原地确认，不自动算完成、不要求去托盘。
- 完成后收起休息窗口，回到沐比身边并显示单次完成反馈。
- 手动完成同类待回应项时消除该事项，避免重复计数。
- 不全屏、不锁定，不要求用户一直看屏幕。拉伸不舒服就停。

## 辅助窗口

窗口采用紧凑标题栏、关闭按钮、窗口内分段与内容滚动区，不出现网页导航、宣传标题或产品页脚。窗口内切换保留各分段滚动位置。

今日：状态、今日活跃、本轮连续活跃、三类回应与触发次数。活跃代表使用电脑，不是运动。主窗口与洞察的当前连续活跃取同一状态。

历史：7/30 天范围、柱形点击详情、当前连续、今日最长、近 30 天最长与活跃日均。没有记录时不编造数据。

设置恰好四项：提示音、免打扰时段（含起止时间）、开机自启、语言。节奏为固定默认，不增加间隔配置。

关于保留版本、官网、反馈、检查更新与数据位置。自动检查更新为固定策略，不成为第五个设置项。未知地址不猜测，未连接能力不伪造成功。

## 视觉规范

Token 集中于共享样式；角色色与当前品牌保持一致。桌面底色与应用窗口色分开，不把网页画布当产品背景。

| 用途 | Light | Dark |
|---|---|---|
| 工作区示意 | #CCD7D7 | #1C272C |
| 窗口背景 | #F8F7F3 | #282622 |
| 标题栏 | #F0EEE8 | #302D28 |
| 文字 | #26241F | #F1EBDF |
| 次级文字 | #655F55 | #C0B5A4 |
| 强调 | #A7472C | #EFAA85 |

沐比身体 #F6EEDF、高光 #FBF5E9、深部 #E8D7BE、面部 #2D2A28，暗色不反相。角色日常约 112px 宽，窗口与提醒使用 12–18px 文本，正文说明不靠过淡色表达层级。标题栏和菜单按桌面控件密度处理，不采用营销页大字。

主内容使用正常 grid/flex 文档流；角色拖动位移是用户直接操纵结果，不用位移堆叠初始页面布局。375px 窄预览中窗口与宠物按纵向排列，不模拟手机产品，也不隐藏关键入口。

所有功能图标使用同一线性 SVG 语汇，具有受控尺寸；不使用 emoji 功能图标。焦点可见，状态有文字，不只靠颜色。

## 两平台共同规格（macOS + Windows，issue #169）

下表为设计要求，不代表宿主能力已验证。

| 交互 | macOS | Windows |
|---|---|---|
| 常驻系统入口 | 菜单栏状态项 | 通知区域图标 |
| 无系统入口时 | 宠物旁菜单与辅助窗口可达 | 同一兜底逻辑 |
| 主点击/摸摸 | 陪伴反馈，不记录完成 | 同一语义 |
| 拖动本体 | 拎起、移动、落位 | 同一语义 |
| 完成/部分完成 | 明确按钮提交 | 同一语义 |
| 关闭辅助窗口 | 收窗，继续提醒 | 同一语义 |
| 退出应用 | 明确菜单并确认 | 同一语义 |
| 键盘 | Tab、Enter/空格、方向键、Esc | 同一语义 |
| 宠物常驻与邀请投递 | 常驻宠物窗口，邀请贴身等待 | 同一语义 |
| 原生窗口机制 | 按平台标准窗口实现 | 按平台标准窗口实现 |

快捷键语义一致，实际修饰键、菜单样式、标题栏与无障碍 API 由宿主按平台惯例实现。原型不提供平台切换器，不把任一平台的窗口机制硬套给其他平台。

## 需由宿主实现和验证的边界

透明角色窗口、到点置顶但不抢焦点、非交互区域点击穿透、系统菜单栏/托盘、窗口管理、系统提示音、开机自启、实际本地数据目录均未连接。浏览器里的菜单与标题栏只表达交互规格，不是真实系统集成。

多显示器：同一时间只在一个工作区呈现一个沐比；不主动穿过文档中心。需验证显示器边界、缩放、热插拔、睡眠唤醒、全屏应用和不同桌面环境。受限时保留手动复位与辅助窗口入口，不默默丢失提醒。

未配置官网或反馈地址时只告知暂不可用，不跳转到猜测地址；未连接更新服务时不宣称已是最新版。

## 数据与原型状态

非空态入口在浏览器存储可用时共享状态；首日空态使用独立零数据。不可存储时退回当前会话，并在设置窗口说明。

已有历史是固定在 11 月 5–11 日的示例，不是用户数据。浏览器可见页面时间仅近似用于演示活跃节奏，不能检测系统输入或离席，不得作为引擎实现方案。7/30 天选择显示范围内已有记录，不补造整月记录。

中英文与跟随系统继续保留；正式宿主仍以 `shared/i18n/{zh,en}.json` 为文案单源。

本轮完成桌面形态、宠物操作、辅助窗口与六个入口的源文件调整，未运行测试、渲染检查或两端宿主验收。原型落账与产品代码实现不在本轮范围，不声明设计已冻结。
