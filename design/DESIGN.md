# MoveBit DESIGN.md — 视觉与交互契约（单一真源）

原型（`design/prototype/`）与实现（`macos-host/`、`windows/`、`linux/`）都遵循本文件；改视觉先改这里，再同步实现。
Tokens 逐值提取自现行实现：`macos-host/Sources/RivetHost/MainView.swift` 的 `Palette`（唯一成对的亮暗源）、`linux/src/main.cpp` 的 `apply_global_css`、`windows/MainWindow.xaml`（亮色与 macOS 对齐）；沐比角色色提取自 `assets/mubi/tokens.json`（#56 设计冻结的单一真源）；文案逐字取自 `shared/i18n/zh.json`（i18n 单源、zh 为默认）。

## Brief（2026-11-11，原型先行 rollout）

- **目标**：非从零重设计。v0.0.1 重启版已是「小而诚实」的休息提醒工具（无全屏强制休息、无设置迷宫），本契约把三端宿主的现有视觉收敛成一份可执行的单一真源：把「一个沐比、一条合并邀请、多显示器不缺席」这个产品主角在界面上站出来；补齐 Windows/Linux 的暗色欠账（macOS 已亮暗跟随系统）；界面达到可直接用于官网宣传的质量。
- **原型范围**（6 屏 × 亮/暗）：
  ① `desktop.html` — 英雄屏：多显示器桌面上的合并邀请（久坐+喝水合并、沐比等待应答、托盘状态）；
  ② `main.html` — 主窗口「设置与统计」（今日活跃 / 7 天历史 / 洞察 / 四控件设置 / 关于）；
  ③ `empty.html` — 首日空态（0 分钟、暂无历史、暂无洞察）；
  ④ `micro.html` — 护眼/微休息卡三态（邀请 → 20 秒倒计时 → 结束）；
  ⑤ `tray.html` — 托盘菜单与暂停态（做到了 / 稍后再说 / 隐藏 / 专注 / 暂停 1 小时）；
  ⑥ `onboarding.html` — 首次见面（一屏、一句话、一个开始）。
- **Exit 条件**：6 屏关键状态齐（含空态/进行态/合并态）+ 交互逻辑定稿 + HIG 清单全过 + 用户评审通过。
- **不在范围**：新功能、新设置项、节奏可配置化（均衡节奏是产品默认，#140）、全屏/强制休息（owner 决定永不回归）、路由/契约变更（不动 `rivet-schema.json`）、商业/付费 UI、更换角色美术（`assets/mubi/` 已冻结）。

## 设计原则（HIG 内核）

- **提醒不可错过，但绝不打扰**：邀请 topmost、持久、必须回答——但永不抢键盘焦点、永不全屏遮罩、沐比之外全部点击穿透。等待是邀请的一部分，压力来自存在感而不是阻断。
- **诚实优于好看**：Done 是自我报告，永远不是测量。界面任何地方不得暗示「已验证你喝过水/休息过」；倒计时走完 ≠ 完成；文案主动承认这一点（`today.outcomeLegend`）。
- **一个沐比，一条邀请**：多条到点提醒合并成一条邀请（含义一个不丢）；角色只有一态一手势；三层表面封顶，装饰永远不与提醒文本争注意力。
- **多显示器一份契约**：沐比同一时刻只存在于指针所在工作区的一个显示器上，按显示器 clamp、绝不自主越过文档中心；三端交互一致（拖拽即移动、抚摸即完成、稍后即延后）。
- **反馈及时**：状态点（运行/暂停）、下一条提醒倒计时、配置保存时间戳，全部即时可见；暂停/专注是即时动作，不是新模式。
- **角色是载体不是商品**：沐比是健康提醒的载体（charter #51），健康节奏比角色定制优先；设置只有四个控件，其余皆产品默认。

## Tokens（语义；值不在此复制）

### 壳层（窗口 UI）

值类 token 真源 = 现行实现（`macos-host/Sources/RivetHost/MainView.swift` 的 `Palette`——唯一成对的亮暗源 · `linux/src/main.cpp` 的 `apply_global_css` · `windows/MainWindow.xaml`）；原型 `design/prototype/shared.css` 与其一一对应，本表只记语义。

| Token | 语义 |
|---|---|
| `--bg --surface --line` | 暖纸画布 / 卡片菜单浮层 / 分隔描边 |
| `--ink --ink-2 --ink-3` | 主/次级/辅助文字三档 |
| `--accent --accent-soft` | 交互与状态：主按钮/链接/进行态/下一条提醒 + 弱底 |
| `--track --chart` | 进度条槽图块底 / 历史图非今日柱 |
| `--running --paused --water` | 状态点：运行（双态同值）/ 暂停（双态同值，兼久坐类 accent）/ 喝水类 accent（图表/计数） |

### 沐比角色（值真源 = `assets/mubi/tokens.json`，#56 设计冻结；双主题独立艺术指导、永不自动反相）

| Token | 语义 |
|---|---|
| `--mubi-body --mubi-light --mubi-deep --mubi-shadow` | 身体暖象牙主色 + 体积渐变（左上光→右下沉）+ 形体接触阴影（永不做深色描边；暗色保持暖象牙不减饱和） |
| `--mubi-ink --mubi-fin` | 眼睛与必要面部细节 / 叶鳍 |
| `--mubi-capsule --mubi-capsule-ink` | 提示胶囊低眩光面与文字（亮暗各值） |
| `--cue-water --cue-move --cue-eyes --cue-done --cue-focus` | 健康语义色：只出现在沐比小面积元素（杯/拉伸提示/远眺/完成微光/专注环），绝不作背景或图表主色 |

- **字体**：系统栈 `system-ui, -apple-system, "Segoe UI", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei"`。字号取自 GTK `apply_global_css`：大数字 44px/700 · 计数与行 14px/600 · 正文 13px · 次级 12.5–11.5px · 脚注 11px · 胶囊 12px/600 · 提醒标题 17px/600。
- **圆角**：卡片 16px · 图块 12px · 胶囊 12px · 微休息卡 18px · 控件 6–8px · 药丸全圆。**间距节奏**：6/10/14/20。**动效**：标签淡入 160–220ms、可见 4–6s、淡出 180–240ms；每条邀请只配一个表达手势；Reduce Motion → 实际到点类型的静态姿势 + 同文案同操作。
- **尺寸**：沐比身体高度 S 60 / M 78（默认）/ L 104 逻辑单位，身体高度是契约，窗口可为鳍/道具/标签长大。
- **语言**：界面文案 zh/en 双源（`shared/i18n/{zh,en}.json`，zh 为默认）；原型取 zh 现行文案。已知文案债：`ob.hello`/`copy.*Pool` 中的「水滴」旧人称与 #56 角色名「沐比」不一致，评审后统一为沐比。

## 组件词汇

`MainShell`（两栏主窗口：左 今日/历史/洞察，右 设置/关于）· `TodayCard`（状态点可点击暂停/恢复、44px 活跃大数字、久坐进度条、🚶💧👀 三计数器、下一条提醒）· `HistoryChart`（7/30 天切换、今日柱 accent、tooltip：日期/活跃/提醒次数/最长连续）· `InsightGrid`（四宫格 + 最活跃日 + 一句洞察）· `SettingsForm`（提示音/免打扰时段/开机自启/语言，恰好四控件）· `AboutBlock`（版本/更新/数据目录）· `MubiCompanion`（角色 + 提示胶囊 + 稍后再说药丸；抚摸=完成）· `CueCapsule`（合并邀请文案，每类一行，至多三行换行）· `LaterPill`（表面唯一非抚摸应答路径）· `MicroCard`（顶部居中卡：邀请态/20 秒倒计时/结束态，细进度条收缩）· `TrayMenu`（设置与统计/专注/暂停 1 小时/20 秒护眼/2 分钟拉伸/复位沐比/检查更新/退出）· `OnboardingCard`（460×520 一屏三句话）。

## 不变式

1. `--accent` 只用于：主按钮、链接、进行态、下一条提醒与「今日」数据高亮；禁止大面积色块。健康语义色（`--cue-*`）只出现在沐比相关小元素上，绝不作背景或图表主色（图表主色是 `--chart` + 今日 `--accent`）。
2. 邀请永不自动消失、永不堆积：新的到点提醒合并进已打开的同一条邀请（种类并集）；胶囊上只有「稍后再说」一个应答控件，其余应答（做到了/隐藏/专注/暂停）一律走托盘；点击邀请外部什么都不发生。
3. 完成永远自我报告：没有用户显式点击（抚摸沐比/托盘「做到了」/卡片「做好了」），任何界面不得把提醒标为完成；倒计时走完只显示结束提示，不写完成数。
4. 层级三层封顶：`--bg` < `--surface`（卡片/菜单/胶囊）< `--track`（图块/槽）；层级靠 `--line` 分隔与一层轻阴影表达，不堆阴影、不重描边。
5. 亮暗成对：不存在只有一态的界面。暗色独立艺术指导——壳层用上表暗值，沐比保持暖象牙、rim light 0.45 → 0.30、胶囊换低眩光面，永不自动反相；Windows/Linux 当前亮色-only 是已记录欠账，向本契约收敛。
6. 无障碍契约：提醒文本 4.5:1、必要非文本 3:1（以 `--ink`/`--ink-2` 调面对比，不假设 accent 色可作正文）；Reduce Motion 全局降级为静态姿势；沐比永不捕获指针——拖拽仅发生在沐比本体上，其余表面全穿透。
