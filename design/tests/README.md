## 验证范围与限制

这不是浏览器渲染或三平台原生实测。

- Chromium 启动尝试被系统拒绝：Mach rendezvous 的 `bootstrap_check_in` 返回 Permission denied。
- 浏览器访问宿主不可用；计算机操作工具未获准操作 Edge 或 Open Design，因此未能直接操作实际预览。
- DOM 测试使用 jsdom。窗口矩形、指针捕获和 dialog 的原生部分由测试环境建模；因此不能证明实际像素命中、操作系统指针捕获、视觉边界或浏览器原生焦点/对话框完全正确。
- 受控时钟用于检查逻辑时序，不模拟系统睡眠、真实离席或后台节流。
- macOS、Windows、Linux 的系统托盘、透明窗口、置顶、穿透与跨屏交互仍需对应宿主实测，本次没有验证它们。

## 复现方式

使用 `tests/package.json` 锁定的开发依赖与符合 engines 的 Node.js：

```sh
npm --prefix tests install
npm --prefix tests test
```

本次实际使用 Node.js 26.12.0，依赖仅安装在系统临时目录，使用以下调用运行相同测试，没有为产品添加运行时依赖：

```sh
NODE_PATH=/tmp/movebit-interaction-check/node_modules node tests/interaction.test.cjs
```

测试读取实际入口与脚本，不改写或导出产品状态，不访问外部网址，不接触用户真实浏览器数据。
